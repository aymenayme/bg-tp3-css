Web Dev Academy

Apprenez les quatre piliers du développement web : HTML, CSS, JavaScript et HTTP, puis mettez-les en pratique dans un vrai projet.

Découvrir le programme

HTML

HTML structure le contenu d'une page : titres, paragraphes, liens, images, tableaux et formulaires, grâce à des balises sémantiques.

Lire plus

CSS

CSS met la page en forme : couleurs, polices, espacements et mises en page adaptables avec Flexbox, Grid et les media queries.

Lire plus

JavaScript

JavaScript rend la page vivante : il réagit aux actions de l'utilisateur, modifie le DOM et échange des données avec le serveur.

Lire plus

HTTP

HTTP est le protocole qui relie navigateur et serveur : il définit les requêtes, les réponses, les méthodes GET et POST et les codes de statut.

Lire plus

Comprendre comment fonctionne le web

Une page web naît de la combinaison de trois langages : HTML pour la structure, CSS pour le style et JavaScript pour l'interactivité, le tout transporté par HTTP. À la fin du cours, vous saurez les assembler pour réaliser votre propre site.
